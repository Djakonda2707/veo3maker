# Лендинг конференции «ИИ для дизайна интерьера и архитектуры»

Продающий одностраничный сайт двухдневной онлайн-конференции (6–7 июня 2026)
для дизайнеров интерьера и архитекторов. Стек: **React + Vite + TypeScript**.

## Как редактировать контент

Весь текст, цены, даты и ссылки лежат в одном файле:

```
src/data/content.ts
```

Что обязательно заменить перед публикацией:

| Поле           | Что это                                  |
| -------------- | ---------------------------------------- |
| `paymentUrl`   | Ссылка на страницу оплаты (кнопка CTA)   |
| `telegramUrl`  | Ваш Telegram для связи                   |
| `email`        | Email для связи                          |
| `priceRaiseAt` | Момент повышения цены (таймер считает к нему) |

Цены, программа дней, бонусы и FAQ — там же.

## Запуск

```bash
npm install
npm run dev      # дев-сервер: http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # предпросмотр собранного сайта
```

## Деплой

После `npm run build` папка `dist/` — это готовый статический сайт.
Залейте её на любой хостинг: GitHub Pages, Netlify, Vercel или обычный хостинг.
В `vite.config.ts` уже задан `base: './'` — сайт работает из любой подпапки.
